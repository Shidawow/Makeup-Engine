# Full-region Fixture Coverage

Phase 6F adds a deterministic full-region fixture covering:

- lips
- blush
- eyeshadow
- eyeliner
- contour
- highlight

The fixture uses synthetic 3x3 pixel artifacts and reviewed/training-ready split rows across train, validation, and test. It exists to verify end-to-end training and export readiness for all supported cosmetic regions.

It is not a real face dataset and should not be used as a quality benchmark.
