# Evaluation Report

Phase 6B evaluation reports are dry-run reports. They do not compute real model
IoU, Dice, precision, or recall.

Current report content:

- dataset summary
- split balance
- region coverage
- dry-run proxy mask area
- dry-run proxy diff area
- quality weighted sample count
- failed sample summary
- readiness status

Proxy metrics are explicitly labeled as dry-run proxies. They are intended for
pipeline readiness checks, not model quality claims.
