# Trial Template Selection

Phase 8D defines how templates are selected for a limited real user trial.

## Selection Rules

The core trial-ready set must include:

- at least one beginner-friendly template
- at least one short-duration template
- at least one natural or daily style template

The selection model avoids:

- high-complexity templates as the first core trial path
- missing steps
- missing tools
- missing region instructions
- blocked content QA reports
- internal technical terms in user-facing copy

Warning templates can be kept as backup templates only. They must be marked clearly in the trial script and must not silently become the first user task.

Blocked templates cannot enter the trial-ready set.

## Boundary

Selection is local-only and deterministic. It does not call recommendation APIs, OpenAI, external AI/CV services, analytics, backend, or cloud sync. It does not collect user photos or real user trial records.
