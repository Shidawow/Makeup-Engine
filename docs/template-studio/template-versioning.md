# Template Versioning

Phase 6J uses deterministic semantic versions for library entries and publish packages.

## Initial Version

The initial library template version is `0.1.0`.

This matches the current MVP state: templates are useful local assets, but the downstream consumption contract is not yet locked.

## Bumps

- `patch`: copy, tags, small metadata corrections
- `minor`: steps, parameters, or region instruction changes
- `major`: significant methodology or makeup-region behavior changes

Each version change must be recorded in version history. Publish package export records the package version and entry versions.
