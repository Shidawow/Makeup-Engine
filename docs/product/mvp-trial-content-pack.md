# MVP Trial Content Pack

Phase 13A adds a local MVP trial content pack for founder demo review. It is a
demo content pack, not the formal Template Library and not a published user app
package.

## Trial Templates

The pack includes three founder-demo-ready templates:

- 新手通勤淡妆
- 日系温柔约会妆
- 韩系清透低饱和妆

Each template includes ordinary-user copy, suitable scenarios, difficulty,
estimated time, tools checklist, product placeholders, step guidance, beginner
tips, common mistakes, correction tips, completion checks, and demo risk notes.

## Boundary

- Local MVP trial content only.
- Not official Template Library content.
- Not generated from fully automatic photo extraction.
- Human review remains required before any broader use.
- No registry write.
- No publish.
- No production writer.
- No current User App Shell package replacement.
- No backend, camera, AR, OpenAI/external API, analytics, or training scope.
- No real user photos, names, contacts, health information, sensitive identity
  data, biometric identifiers, local image paths, object URLs, or base64 image
  payloads.

## Demo Use

The content pack supports a founder review route:

1. Open User App MVP.
2. Browse the three trial templates.
3. Choose one template and read its detail.
4. Review preparation and tools.
5. Walk through guided steps.
6. Complete the demo and review local-only privacy copy.
7. Switch to Template Studio operator view only when explaining the production
   workflow and boundaries.

## Forbidden Claims

Founder demo scripts and UI must not claim:

- fully automatic high-quality makeup extraction
- AI confirmed final recognition
- published template
- registry written
- production ready
- medical diagnosis
- exact product shade match

Phase 13A can demonstrate the MVP path and operator workflow, but it cannot
claim production readiness or registry readiness.
