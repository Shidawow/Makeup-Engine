# Internal Trial Prep

Phase 14B turns the passed Phase 14A founder demo into an internal trial prep
pack. It prepares routes, role-only participant profiles, safe feedback
prompts, checklist items, and boundary reminders for a future small-scope dry
run.

14B is not a public beta, not a real user research system, not production
readiness, and not analytics.

## Goals

- Define who can be represented in the trial as role profiles.
- Define what the internal trial should observe.
- Define how the trial route should run.
- Define what must be checked before the trial.
- Define what trial participants must not misunderstand.
- Define what anonymous feedback can be recorded.
- Define what data must never be collected.
- Decide whether the local MVP can enter Phase 14C Internal Trial Dry Run.

## Participant Role Profiles

Participant profiles are role-only categories, not identities:

- founder
- friend_or_family
- makeup_beginner
- makeup_interested_user
- operator_reviewer
- product_reviewer

The prep pack must not record real names, phone numbers, emails, social media
accounts, precise addresses, photos, health information, sensitive identity
information, biometric identifiers, face embeddings, analytics ids, or backend
records.

## Trial Routes

- User App MVP trial: ordinary user flow through home, template, preparation,
  steps, and completion.
- Mobile demo trial: narrow-screen usability, touch actions, text comfort, and
  sticky action behavior.
- Template content review: three local trial templates, clarity, attractiveness,
  and followability.
- Photo-to-template operator demo: operator explanation of FaceMesh, region QA,
  candidates, draft-only output, and human review.
- Boundary understanding check: confirm the trial does not look like public
  beta, analytics, automatic personal recognition, registry write, publish, or
  production app launch.

## Boundaries

14B keeps the registry chain paused after Phase 10U. It does not resume Phase
10V or any real write authorization path.

14B does not add backend, database, account, analytics, payment, camera, AR,
OpenAI API, external AI API, training, native app scope, public recruitment, or
production publishing.

The current MVP remains a local demo. Trial content remains local demo content,
not official Template Library content.
