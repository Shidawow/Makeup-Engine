# Anonymous Internal Trial Gap Action Plan

Phase 9J maps anonymous evidence gaps into concrete administrator actions. It
is a local planning aid, not an issue tracker, backend record system, production
analytics tool, or public roadmap.

## Priority Rules

- forbidden data or privacy incidents must become `p0_privacy_blocker`
- missing participant notice must be at least `p1_required_before_next_trial`
- missing admin script must be at least `p1_required_before_next_trial`
- missing stop conditions must be at least `p1_required_before_next_trial`
- missing post-launch handoff must be at least `p1_required_before_next_trial`
- insufficient sample size becomes `p2_should_fix` or observation work and
  cannot directly support MVP validation preconditions
- low confidence issues become `p3_observe`

## Owner Areas

- launch pack
- participant notice
- admin script
- evidence collection protocol
- evidence capture sheet
- stop conditions
- post-launch handoff
- privacy boundary
- trial content
- user app shell
- no action / observe more

## Acceptance Criteria

Every action must preserve the same boundary: anonymous, internal, local,
review-only, no photos, no upload, no training, no backend, no AI analysis, and
no real user records in `project-state`.
