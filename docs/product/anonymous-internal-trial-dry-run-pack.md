# Anonymous Internal Trial Dry Run Pack

Phase 9G defines a local anonymous dry run pack for rehearsing the internal trial flow before any real anonymous internal trial begins. It is not production release, public recruitment, backend collection, analytics, AI analysis, training, App Store/TestFlight, or MVP validation planning.

## Purpose

The dry run lets the team rehearse the full internal trial path without collecting real personal data. The goal is to check whether the team can explain the participant notice, walk through the User App Shell, capture only anonymous notes, trigger stop conditions, and produce a local review decision.

## Required Scenarios

- First-time beginner guided makeup flow.
- Template discovery and selection flow.
- Step guidance comprehension flow.
- Privacy notice comprehension flow.
- Administrator evidence capture rehearsal.
- Stop condition rehearsal.

## Participant Notice

Before the dry run starts, the administrator must explain:

- This is anonymous, local, and rehearsal-only.
- No photos are collected.
- Nothing is uploaded.
- Nothing is used for model training.
- No real name, contact information, health information, sensitive identity information, or biometric information is collected.
- The administrator records only anonymous observations and aggregate summaries.

## Allowed Dry Run Evidence

Allowed evidence remains anonymous and local:

- Anonymous task completion notes.
- Anonymous step comprehension notes.
- Anonymous template value notes.
- Anonymous Shell usability notes.
- Anonymous recommendation usefulness notes.
- Anonymous privacy clarity notes.
- Anonymous trial operations notes.
- Aggregated issue counts.
- Aggregated severity summaries.
- Aggregated iteration priority summaries.

## Forbidden Data

Never record real names, phone numbers, email, precise address, face photos, makeup photos, skin health information, health condition, sensitive identity, biometric identifier, face embedding, raw camera data, uploaded image, social media account, payment information, account credential, or training dataset write request.

## Stop Conditions

Stop the dry run or stop recording immediately if anyone asks for a photo, camera access, upload, real identity, contact information, health information, sensitive identity, biometric data, backend storage, AI automatic analysis, or training usage.

## Result

The dry run can recommend Phase 9H only when the pack, participant notice, checklist, stop conditions, and Phase 9F evidence collection quality gate are all ready. It must not skip to production app work or MVP validation planning.
