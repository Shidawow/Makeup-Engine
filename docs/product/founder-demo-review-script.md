# Founder Demo Review Script

Phase 13A defines a founder-facing demo review script for checking whether the
MVP trial content and current User App path are understandable enough to collect
structured founder feedback in Phase 13B.

## Review Position

Founder Demo Review is not a launch review. It is an internal review of:

- first impression of the User App MVP
- template selection clarity
- template detail clarity
- preparation page clarity
- step guidance clarity
- completion page satisfaction
- mobile demo usability
- MVP trial content quality
- operator workflow explainability
- photo-to-template boundary clarity
- privacy boundary clarity
- next iteration readiness

## Demo Script

1. Start on the ordinary User App MVP path.
2. Confirm the first screen explains what the user can do.
3. Browse 新手通勤淡妆, 日系温柔约会妆, and 韩系清透低饱和妆.
4. Open a template detail page and read the summary, difficulty, time, scenarios,
   tools, and preparation.
5. Walk through at least three guided steps.
6. Check completion copy and local-only privacy copy.
7. If needed, open Template Studio operator view to explain photo-to-template
   draft workflow, Draft Preview QA, Acceptance Trial, and Founder Demo Review.
8. Explicitly state that all photo-to-template output is draft/candidate-only
   and requires human review.
9. Explicitly state that registry writes, publish, production writers, and User
   App Shell replacement remain blocked.

## Stop Conditions

Pause the demo review if any of the following appears:

- ordinary user path exposes Template Studio, registry, production writer,
  Founder Demo Review, trial content pack, Draft Preview QA, or Acceptance Trial
  terminology
- the demo claims fully automatic high-quality extraction
- the demo claims AI confirmed final recognition
- the demo claims publish, registry written, production ready, or production
  writer creation
- privacy copy suggests uploading, storing, training on, or collecting real user
  photos or personal data
- fewer than two complete trial templates are available

## Phase 13B Handoff

If Founder Demo Review is ready or ready with warnings, the next phase is
Phase 13B - Founder Trial Feedback Capture & MVP Gap Prioritization. Phase 13B
should capture founder feedback and prioritize MVP gaps; it still must not
resume Phase 10V or perform registry writes.
