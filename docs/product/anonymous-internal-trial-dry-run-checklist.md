# Anonymous Internal Trial Dry Run Checklist

Phase 9G checklist is the administrator safety checklist for rehearsing an anonymous internal trial. It is not a backend form and must not store real user records.

## Before Dry Run

- Confirm the dry run pack is ready.
- Confirm the six required dry run scenarios are ready.
- Confirm the Phase 9F evidence collection protocol and quality gate remain ready.
- Confirm this is rehearsal-only and not a real public trial.

## Participant Notice

- Confirm the participant has heard that the dry run is anonymous, local, and rehearsal-only.
- Confirm no photos are collected.
- Confirm nothing is uploaded.
- Confirm nothing is used for training.
- Confirm no real name, contact information, health information, sensitive identity information, or biometric information is collected.

## Administrator Rehearsal

- Use the session script.
- Walk through template discovery, template detail, step guidance, privacy notice, and local progress.
- Record only anonymous observations or aggregate issue counts.
- Do not write real user records into `project-state`.
- Do not use AI automatic analysis.

## Allowed Evidence

Allowed evidence includes anonymous task completion notes, anonymous step comprehension notes, anonymous template value notes, anonymous Shell usability notes, anonymous recommendation usefulness notes, anonymous privacy clarity notes, anonymous trial operations notes, and aggregate summaries.

## Forbidden Data

Stop if any request involves photos, contact information, uploads, training data, real identity, health information, sensitive identity, biometric identifiers, account credentials, payment information, or social accounts.

## After Dry Run

- Review only anonymous notes and aggregate summaries.
- Delete or discard any accidental identifying content.
- Record whether the dry run should repeat, revise protocol, revise checklist, stop for privacy/scope, or prepare Phase 9H.
