# Template Content QA Checklist

Use this checklist before a small-scope real user trial.

## Required

- The core trial-ready set includes a beginner-friendly template.
- The core trial-ready set includes a short-duration template.
- The core trial-ready set includes a natural or daily style template.
- Each template has a clear user-facing title.
- Each template has a clear summary or subtitle.
- Each template has at least three actionable steps.
- Step text tells the user what to do, where to do it, and what effect to expect.
- Every step region has a matching region instruction.
- Tools and products are understandable without brand-specific requirements.
- Recommendation reasons explain why the template fits the user path.
- Privacy and placeholder copy says photos, camera, AR, backend upload, and training are not enabled.

## Block Before Trial

- Missing steps.
- Missing core region instructions.
- Internal technical terms in user-facing copy.
- Compatibility blocking issues.
- Copy that implies upload, camera, AR, backend, AI generation, or training is active.
- Any flow that collects real photos, names, contact information, health information, sensitive identity information, biometrics, backend records, analytics records, or training data.

## Warning Only

- Longer templates.
- Medium or advanced complexity.
- Compatibility warnings that do not block guidance.
- Templates that are useful as backup but not suitable for the first trial task.
