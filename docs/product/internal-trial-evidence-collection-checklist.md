# Internal Trial Evidence Collection Checklist

Phase 9F checklist prepares administrators for an anonymous internal trial dry run. It is a local preparation checklist, not a backend form and not real participant record storage.

## Before Trial

- Confirm the evidence collection protocol is ready.
- Read the participant notice in plain language.
- Confirm this is internal and anonymous.
- Confirm no real names, contacts, photos, health information, sensitive identity information, biometrics, or account credentials will be recorded.

## During Trial

- Record only anonymous observations.
- Use participant type or anonymous session labels only.
- Do not ask for photos, uploads, camera access, account login, or health details.
- Stop if a forbidden data request appears.

## After Trial

- Convert notes into aggregated evidence themes, issue counts, severity summaries, and priority summaries.
- Do not save real user records into `project-state`.
- Do not write feedback into training datasets.
- Do not use AI automatic analysis.

## Review Handoff

The handoff can reference only local anonymous summaries and documented evidence quality. It must not become production analytics, backend collection, public recruitment, production release approval, or MVP validation approval by itself.
