# Internal Founder Demo Run Checklist

Use this checklist during Phase 14A. It is for internal founder demo operation
only and does not create production readiness.

## Before Demo

- Confirm `npm run mediapipe:check` passes or prepare the MediaPipe recovery
  explanation.
- Confirm the ordinary User App path opens by default.
- Confirm the three trial templates are present.
- Confirm Template Studio operator panels are available only in the operator
  area.
- Confirm registry chain remains paused after Phase 10U.

## Route Checks

- Route A User App MVP: home, discovery, detail, preparation, steps, completion.
- Route B Vision Analysis: FaceMesh, mask, Region QA, readiness score label.
- Route C Template Studio: candidates, drafts, QA, human review, handoff.
- Route D Mobile: narrow-screen tap targets and sticky actions.
- Route E Boundary: no publish, no registry write, no production writer, no real
  user research.

## Stop Conditions

Stop the demo or mark Phase 14A blocked if any of these appear:

- Ordinary user path exposes internal founder demo or registry terminology.
- Any panel says a template is published or registry written.
- Any panel says a production writer is active.
- Any copy claims automatic high-quality extraction or AI-confirmed recognition.
- Any flow asks for real names, contact information, photos, health data,
  biometrics, analytics identifiers, base64 images, or local photo paths.
- Any flow implies founder notes are real user research or training data.

## Pass Result

If all routes pass, record the decision as internal trial preparation readiness
and recommend Phase 14B - Internal Trial Prep.

If the demo has blockers, recommend Phase 13E - MVP Demo Gap Resolution Sprint 2.
