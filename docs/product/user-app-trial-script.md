# User App Trial Script

Phase 8C trial script for internal / small-scope user validation.

## Before Trial

- Use the local mobile Web/PWA shell only.
- Explain that the shell is a prototype, not the production app.
- Explain that photos, camera, AR, login, upload, backend, analytics, and training are not enabled.
- Ask the user not to enter name, contact information, photos, health information, or sensitive identity details.

## Trial Flow

1. Ask the user to open the shell and describe what they think they can do next.
2. Ask the user to browse the recommended makeup look.
3. Ask the user to choose one template and read the detail screen.
4. Ask the user to start guidance and complete at least three steps.
5. Ask the user to find tools/products and region guidance.
6. Ask the user to set or skip local preferences.
7. Ask the user to read the privacy notice.
8. Ask the user to save or restore local progress.
9. Ask the user to answer the local feedback questions.

## Success Signal

The trial is useful if it shows whether users understand the flow, are willing to follow it, understand privacy boundaries, and believe the template guidance has value.
