# Project Management Manifest

## Purpose

Make the repository operable as an AI self-driving engineering workspace.

## Core Directives

- Every change must map to a task.
- Every task must map to a workflow.
- Every workflow must map to an owner agent.
- Every owner agent must obey standards.
- Every standard must be testable.

## Documentation Guarantees

- All project management docs are structured.
- All major modules have an explicit owner.
- All tests are tied to architecture goals.
