# Review Workflow

## Purpose

Evaluate architecture, quality, and risk before merge or next stage.

## Flow

1. Check module boundaries.
2. Check type boundaries.
3. Check tests and snapshots.
4. Check runtime determinism.
5. Check complexity and duplication.
6. Check future extension safety.
7. Return findings with severity.

## Output Format

- Findings first.
- Assumptions second.
- Summary last.
