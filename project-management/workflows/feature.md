# Feature Workflow

## Purpose

Deliver a new engine capability end-to-end.

## Flow

1. Analyze architecture impact.
2. Define contract and task graph.
3. Write tests first.
4. Implement engine module.
5. Run unit, integration, snapshot, and architecture tests.
6. Fix failures.
7. Run typecheck and build.
8. Review boundaries and performance.
9. Update docs and roadmap.

## Completion Criteria

- Tests pass.
- Typecheck passes.
- Build passes.
- Docs updated.
- No boundary violations remain.
