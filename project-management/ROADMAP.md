# Makeup Engine Roadmap

## North Star

Build an AI self-driving engineering workspace for the AI Makeup Intelligence Platform.

The platform target is:

```text
Face Analysis
→ Beauty Intelligence
→ Makeup Style Inference
→ Makeup Compiler
→ Runtime Renderer
→ Layer Graph
→ Real-Time Preview
```

## Phase 1: Engine Core Integration

- Establish engine contracts.
- Build pipeline stages.
- Compile plans into render instructions.
- Add mock runtime renderer.
- Add engine integration tests.

Status: active foundation complete.

## MVP Focus

- Face analysis schema.
- Rule engine.
- Style inference.
- Makeup plan generator.
- Pipeline orchestration.
- Vitest coverage for all core modules.

Status: in progress.

## Phase 2: Intelligence Depth

- Expand face analysis inputs.
- Add beauty scoring dimensions.
- Add style-specific inference.
- Add rule priority/conflict resolution.

Status: next intelligence expansion.

## Phase 3: Runtime Renderer

- Add deterministic renderer interface tests.
- Add layer blending model.
- Prepare Canvas2D runtime.
- Prepare shader-oriented layer graph.

Status: next runtime/renderer expansion.

## Phase 4: Real-Time Preview

- Connect runtime frames to preview shell.
- Keep UI thin and runtime-driven.
- Add visual validation paths.

Status: UI remains thin; preview must be runtime-driven.

## Phase 5: Platform Interfaces

- API adapter.
- iOS/Metal adapter.
- CV adapter.
- LLM adapter.

Status: future adapters only after core runtime contracts stabilize.

## Phase 6: Autonomous Engineering System

- Maintain agent registry.
- Maintain workflows.
- Maintain prompts.
- Maintain technical debt.
- Maintain testing standards.
- Keep autonomous loop operational.

Status: initialized.
